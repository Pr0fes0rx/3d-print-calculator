## التجربة والتفعيل

النسخة التجريبية مجانية لمدة 30 يوماً

### للتفعيل

1. افتح نافذة التفعيل
2. انسخ **Device ID** وأرسله للمطوّر
3. الصق كود الترخيص الذي يصلك
4. التفعيل يتم بدون إنترنت، والكود المرتبط بجهاز واحد لا يعمل على جهاز آخر

### حماية الترخيص

يستخدم البرنامج **License v2**

- Ed25519 للتحقق من صحة الترخيص
- مفتاح عشوائي جديد لكل عميل
- ربط الكود بمعرّف جهاز واحد
- مفتاح إصدار التراخيص منفصل عن مفتاح توقيع التحديثات
- تخزين حالة التفعيل خارج مجلد البرنامج في عدة أماكن
- حماية إضافية عبر Windows DPAPI عند توفره

### ملاحظة مهمة

التفعيل الأوفلاين يمكن أن يستمر بعد حذف البرنامج وإعادة تثبيته لأن بياناته محفوظة خارج مجلد التطبيق

لا يمكن ضمان بقائه بعد فورمات كامل لنظام Windows أو مسح القرص، لأن التخزين المحلي ومعرّف الجهاز قد يتغيران

لا يتم إرسال كود التفعيل أو البيانات الشخصية إلى خادم

فحص التحديث يتم عبر GitHub، وتحديث سعر الصرف اختياري

# English

## Features

- Calculate material, failure, electricity, maintenance, and profit margin costs
- Analyze G-code and 3MF files, including weight, print time, layers, materials, and colors
- Estimate STL costs with Fast, Normal, and Quality profiles
- Automatically monitor the export folder
- Generate PDF invoices with multiple languages and currencies
- Supports PLA, ABS, PETG, TPU, and Resin materials
- Printer power-consumption database
- Arabic and English interface with Dark and Light modes
- Automatic settings persistence
- Works offline for file analysis and license activation
- Digitally signed automatic updates

## Installation

1. Download `3DPrintCalculator_Setup.exe` from the latest Release
2. Run the installer
3. If Windows SmartScreen appears, use **More info → Run anyway**

## Trial and Activation

The trial version is free for 30 days

### Activation

1. Open the activation window
2. Copy your **Device ID** and send it to the developer
3. Paste the license code you receive
4. Activation works offline, and a license bound to one device will not work on another device

### License Protection

The application uses **License v2**

- Ed25519 license verification
- A fresh random key for each customer
- License binding to a single device ID
- Separate license-issuing and update-signing keys
- Activation state stored outside the application folder in multiple locations
- Additional protection through Windows DPAPI when available

### Important Note

Offline activation can survive uninstalling and reinstalling the application because activation data is stored outside the application folder

Activation cannot be guaranteed to survive a full Windows format or disk wipe because local storage and the device identifier may change

No activation code or personal data is sent to a server

Update checks use GitHub, while currency-rate updates are optional

## Privacy

Print-file analysis is performed locally on the device
