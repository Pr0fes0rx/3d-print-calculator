# 3D Print Calculator
### حاسبة تكلفة الطباعة ثلاثية الأبعاد

اعرف التكلفة الحقيقية وسعر البيع الصحيح لكل طلبية طباعة.

**[⬇ تحميل آخر إصدار / Download latest](../../releases/latest)**

---

## المميزات

- حساب تكلفة المادة، الفشل، الكهرباء، الصيانة وهامش الربح
- تحليل G-code و3MF وقراءة الوزن والوقت والطبقات والخامات والألوان
- تقدير STL ببروفايلات سريعة / عادية / جودة
- مراقبة مجلد التصدير تلقائياً
- فاتورة PDF بعدة لغات وعملات
- خامات PLA وABS وPETG وTPU وResin
- قاعدة بيانات لاستهلاك الطابعات
- واجهة عربية وإنجليزية، Dark / Light
- حفظ تلقائي للإعدادات
- يعمل أوفلاين لتحليل الملفات والتفعيل
- تحديثات تلقائية موقعة رقمياً

## التثبيت

1. نزّل `3DPrintCalculator_Setup.exe` من آخر Release.
2. شغّل برنامج التثبيت.
3. إذا ظهرت رسالة Windows SmartScreen استخدم **More info → Run anyway**.

## التجربة والتفعيل

النسخة التجريبية مجانية لمدة 30 يوماً.

للتفعيل:
1. افتح نافذة التفعيل.
2. انسخ **Device ID** وأرسله للمطوّر.
3. الصق كود الترخيص الذي يصلك.
4. التفعيل يتم بدون إنترنت، والكود المرتبط بجهاز واحد لا يعمل على جهاز آخر.

### حماية الترخيص

يستخدم البرنامج License v2:
- Ed25519 للتحقق من صحة الترخيص.
- مفتاح عشوائي جديد لكل عميل.
- ربط الكود بمعرّف جهاز واحد.
- مفتاح إصدار التراخيص منفصل عن مفتاح توقيع التحديثات.
- تخزين حالة التفعيل خارج مجلد البرنامج في عدة أماكن.
- حماية إضافية عبر Windows DPAPI عند توفره.

**ملاحظة مهمة:** التفعيل الأوفلاين يمكن أن يستمر بعد حذف البرنامج وإعادة تثبيته لأن بياناته محفوظة خارج مجلد التطبيق. لا يمكن ضمان بقائه بعد فورمات كامل لنظام Windows أو مسح القرص، لأن التخزين المحلي ومعرّف الجهاز قد يتغيران.

لا يتم إرسال كود التفعيل أو البيانات الشخصية إلى خادم. فحص التحديث يتم عبر GitHub، وتحديث سعر الصرف اختياري.
